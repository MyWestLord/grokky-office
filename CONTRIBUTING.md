# Contributing to GROKKY HQ

Want to hire a new Grokbot for the office? PRs are welcome.

- **New role:** add a block to `office.yaml` and an 800×800 avatar to `assets/avatars/<id>.png`.
- **New squad:** add one line under `squads:` in `office.yaml`.
- **Dashboard:** everything lives in `web/index.html` (no build step).
- **Ideas:** check the roadmap in the README and open an issue.

Please never commit your `.env` or any API keys.
