# GROKKY HQ: гайд на русском

**Что это.** Свой офис из ИИ-агентов на Гроке. Есть **Босс** и 13 сотрудников-Грокботов. Ты даёшь Боссу одну цель, он раздаёт задачи отделам, все работают параллельно, Босс проверяет каждый отчёт и в конце отдаёт тебе **Daily Brief**. Всё это видно вживую на визуальном дашборде.

<p align="center"><img src="../assets/readme/features.png" width="100%"></p>
<p align="center"><img src="../assets/dashboard_live.gif" width="100%"></p>

**Что видно на дашборде.** Каждый агент живой. Когда работает, он печатает и вокруг летят символы кода. Когда отчёт на проверке у Босса, агент ждёт с «...». Если Босс вернул на доработку, агент потеет и переделывает, а после одобрения подпрыгивает и машет. Первый одобренный получает корону 👑 MVP. Сверху идёт статистика миссии: время, сколько агентов работает, сколько отчётов одобрено и сколько отправлено на доработку. В конце летит конфетти и открывается Daily Brief. Кнопка 🔊 включает звуки.

## Почему это работает

- **Один мозг, много ролей.** Каждый агент — это вызов Grok API со своим системным промтом (ролью) и своим набором инструментов. Роль держит агента в фокусе, поэтому ответы получаются конкретнее, чем у одного «универсального» чата.
- **Живые данные без парсеров.** У xAI есть серверные инструменты `x_search` (поиск по X/Twitter в реальном времени), `web_search` (интернет) и `code_interpreter` (считает и запускает код). Ты просто пишешь в роли, какие инструменты ей можно, и Grok сам ходит в X и в интернет. Ключи Twitter API не нужны.
- **Параллельность.** Отделы работают одновременно (по умолчанию до 6 сразу), поэтому миссия на 10 ролей проходит за минуты.
- **Контроль качества.** Босс читает каждый отчёт и отвечает `APPROVED` или `REVISE` с замечаниями. Агент переделывает работу. Это заметно поднимает качество.
- **Всё в одном файле.** Вся «оргструктура» лежит в `office.yaml`. Новую должность можно добавить без программирования.

## Установка за 5 минут

**1. Скачай проект и поставь зависимости** (нужен Python 3.10+):
```bash
git clone https://github.com/MyWestLord/grokky-office.git
cd grokky-office
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

**2. Запусти в демо-режиме.** Ключ не нужен, ответы будут ненастоящими, но весь офис работает:
```bash
python -m grokky serve
```
Открой в браузере **http://127.0.0.1:8042**, выбери готовую миссию и нажми **START**. Комнаты начнут загораться.

**3. Подключи настоящий Грок:**
1. Зайди на **[console.x.ai](https://console.x.ai)**, создай API key и пополни баланс.
2. Скопируй настройки: `cp .env.example .env` (в Windows: `copy .env.example .env`).
3. Открой `.env` и вставь ключ:
```env
XAI_API_KEY=xai-твой-ключ
GROK_MODEL=grok-4.7
GROK_WORKER_MODEL=
```
4. Перезапусти `python -m grokky serve`. Плашка сменится с **DEMO** на **LIVE**.

> Модели у xAI обновляются. Актуальный список смотри на [docs.x.ai](https://docs.x.ai) и при необходимости поменяй `GROK_MODEL`.

**4. Запуск из терминала без дашборда:**
```bash
python -m grokky run "Сделай брифинг по рынку: акции + крипта + что делают киты"
python -m grokky run "Напиши 3 вирусных поста про ИИ-агентов" --only x-research content qa
python -m grokky loop "Утренний брифинг по крипто-твиттеру" --every 120
python -m grokky roles
```
Все отчёты сохраняются в папку `reports/` в формате Markdown.

- Давай **ограничения**: «без платной рекламы», «только Solana», «тон дерзкий, без эмодзи».
- Для конкретного отряда используй `--only`: `--only x-research content qa` — быстрее и дешевле.

## Отряды (squads)

<p align="center"><img src="../assets/readme/squads.png" width="100%"></p>

Не обязательно гонять весь офис. Отряд — это готовая команда под задачу, и так быстрее и дешевле. В дашборде выбери отряд в выпадающем списке рядом с кнопкой START, в терминале добавь `--squad`:
```bash
python -m grokky run "Запуск токена $GROKKY" --squad launch    # X Research, контент, креатив, PR, комьюнити, PM, QA
python -m grokky run "Брифинг по рынку" --squad trader          # X, окопы, Wall St, киты, аналитик, QA (только бумага)
python -m grokky run "Вырасти аккаунт в нише ИИ" --squad growth  # X, контент, SEO, комьюнити, аналитик
python -m grokky run "Сделай бота для алертов" --squad builder  # инженер, PM, аналитик, QA
python -m grokky run "Утренний брифинг" --squad intel           # X, киты, аналитик, QA
```
Свой отряд добавляется одной строкой в `office.yaml` в блок `squads:`.

## Daily Brief в Telegram

1. В Telegram напиши [@BotFather](https://t.me/BotFather), команда `/newbot`, и скопируй токен.
2. Напиши своему боту любое сообщение, потом узнай свой chat id через [@userinfobot](https://t.me/userinfobot).
3. Впиши оба значения в `.env`:
```env
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=123456789
```
После каждой миссии Босс будет присылать Daily Brief прямо в чат. Вместе с `loop --every 60` получается персональный аналитический отдел в телефоне.

## Как добавить свою должность

Открой `office.yaml` и добавь блок в `roles:`:
```yaml
  - id: sales
    name: Sales / Outreach
    outfit: pr
    color: "#ff5aa8"
    tools: [web_search, x_search]
    prompt: |
      Ты отдел продаж. Найди 20 потенциальных клиентов под цель,
      для каждого напиши, почему он подходит, и короткое персональное сообщение.
```
Перезапусти сервер, и новая комната появится на дашборде. Аватарку положи в `assets/avatars/sales.png` (800×800). Промты для генерации в том же стиле лежат в [PROMPTS.md](PROMPTS.md).

**Идеи для новых отделов:** продажи, рекрутер, саппорт, переводчик, редактор рассылки, охотник за аирдропами, шпион за конкурентами, инвест-релейшнс, мем-лорд, сценарист видео.

## Роадмап

<p align="center"><img src="../assets/readme/roadmap.png" width="100%"></p>

- **Phase 0 · BOOT ✅** — Босс + 13 Грокботов, дашборд, проверка отчётов, демо-режим, CLI.
- **Phase 1 · SQUADS & DELIVERY ✅** — отряды, Daily Brief в Telegram, режим 24/7, аватарки.
- **Phase 2 · OFFICE MEMORY (следующая)** — агенты помнят прошлые отчёты, графики KPI, недельный дайджест, счётчик расходов.
- **Phase 3 · HANDS** — постинг в X в один клик из очереди одобрения, PR в GitHub от инженера, экспорт в Notion/Sheets, боты для Discord и Slack.
- **Phase 4 · OFFICE WORLD** — живой анимированный 3D-офис, где агенты ходят по комнатам, как в ролике, голосовой брифинг Босса, мобильное приложение.
- **Phase 5 · MARKETPLACE** — маркет Грокботов от комьюнити, обмен офисами, XP, уровни и «Сотрудник месяца», мульти-офисы для агентств.

## Как держать офис включённым 24/7

- **Цикл:** `python -m grokky loop "Утренний брифинг" --squad intel --every 60`
- **Cron (Linux/macOS):** `0 8 * * * cd ~/grokky-office && .venv/bin/python -m grokky run "Daily brief" >> office.log 2>&1`
- **VPS:** `python -m grokky serve --host 0.0.0.0`, после чего дашборд открывается с телефона. Обязательно закрой его паролем или VPN: встроенного логина нет.

## Как экономить

- В `GROK_WORKER_MODEL` поставь быструю и дешёвую модель, а умную оставь Боссу.
- Запускай только нужный отряд через `--only`.
- `review: false` в `office.yaml` отключит проверки Босса (дешевле, но качество ниже).
- Поиск по X и вебу у xAI оплачивается за вызов. Цены смотри на [docs.x.ai](https://docs.x.ai).

## Безопасность

- **Никаких реальных сделок.** Трейдинг-роли выдают только аналитику и бумажные сделки. Проект не подключается к биржам и кошелькам. Это не финансовый совет.
- **Никакого автопостинга.** Контент готовится как черновики, публикуешь ты сам.
- Агенты могут ошибаться. Проверяй факты (для этого есть QA) прежде чем действовать.
- Никогда не заливай `.env` с ключом в GitHub. Он уже добавлен в `.gitignore`.
